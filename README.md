# Knitting Row & Stitch Counter Tracker
Track rows and stitches across multiple knitting sections with large tap targets and undo support.
## Features
- Add and remove multiple named sections
- Large +/- buttons for row and stitch counters with per-section undo history
- Notes field per section for pattern details
- All state persisted to localStorage automatically
## Tech
Static SPA · Tailwind CDN · localStorage
